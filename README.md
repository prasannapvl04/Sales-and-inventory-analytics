Hero Honda Bike Orders Analysis
📊 Project Overview

This project analyzes 120 Hero Honda bike orders using Python to understand pricing, revenue, delivery performance, cancellations, and product status.

🛠️ Technologies Used

Python

Pandas

NumPy

Matplotlib

🔍 Analysis Performed

Price statistics and percentiles

Bike type and revenue analysis

Premium order identification

Price range analysis

Delivery delay analysis

Cancelled order analysis

Product status analysis

Cumulative revenue visualization

Price vs. delivery delay correlation

📈 Key Results

Total Orders: 120

Total Revenue: ₹1,16,65,000

Average Price: ₹97,208

Premium Orders: 11

Cancelled Orders: 10 (8.33%)

Late Orders: 32

Highest Revenue Bike Type: Commuter

Price–Delivery Correlation: -0.1015
